# Banner Recipes

![Logo](docs/logo.png)

Add loom recipes for banners, with Banner Packs and banner design import/export.

## Download

You can download the mod from any of these sites:

* [GitHub releases](https://github.com/magicus/banner-recipes/releases)
* [Modrinth versions](https://modrinth.com/mod/banner-recipes/versions)
* [CurseForge](https://www.curseforge.com/minecraft/mc-mods/banner-recipes/files)

## Installation

Install this as you would any other Fabric mod. (I recommend using [Prism Launcher](https://prismlauncher.org/) as Minecraft launcher for modded Minecraft.)

## Support

Do you have any problems with the mod? Please open an issue here on Github.

## Acknowledgements

The weaving mechanism and the idea to import banners from URLs are inspired by [Loombook](https://modrinth.com/mod/loombook).
